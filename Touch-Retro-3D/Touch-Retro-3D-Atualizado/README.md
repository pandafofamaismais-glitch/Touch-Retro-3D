# Touch Retro 3D

Projeto escolar em HTML/CSS/JavaScript com Three.js por CDN.

## Recursos
- 12 fases inspiradas em Mario Kart, Bomberman, Pac-Man, Super Mario Bros., Donkey Kong, Street Fighter, Mortal Kombat, Pokémon, Sonic, Flappy Bird e Guitar Hero.
- Fase 12 mistura mecânicas.
- Seleção de personagem.
- 3D com iluminação, sombras e câmera dinâmica.
- Touch e mouse usando Pointer Events.
- Joystick virtual e botões de ação.
- Dificuldade progressiva.
- Fases com objetivos e duração maior.
- Desbloqueio por progresso via localStorage.
- Sem build tools.

## Rodar localmente
Abra `index.html` no navegador. Se o navegador bloquear recursos locais, use uma extensão/servidor HTTP simples.

## GitHub Pages
1. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
2. No GitHub: Settings > Pages.
3. Em Source, escolha Deploy from a branch.
4. Selecione a branch principal e `/root`.
5. Salve e abra a URL fornecida pelo GitHub.

O jogo usa Three.js por CDN, então a página precisa de acesso à internet para carregar a biblioteca.
